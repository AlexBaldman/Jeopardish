# JeoPARODY Active Roadmap

**Updated:** 2026-08-08  
**Rule:** this is the short active work order. Dated plans explain history and
architecture but do not outrank this sequence.

## 1. Secure The Current Batch

- complete multi-size, light/dark browser review;
- run every code, content, CSS, asset, host, build, smoke, accessibility,
  episode, and visual-fixture gate;
- review the diff, commit one coherent checkpoint, push, and verify deployment.

## 2. Original-IP And Asset Provenance

In parallel, repair the long-term jeoPARODY destination's boot chain and add a
blocking browser parity harness. Do not forward-port broad features until it has
one game-state owner, one component contract, bounded content loading, complete
asset packaging, and no browser credential path.

- create a machine-readable rights manifest for every production asset;
- record source hash, transformation lineage, model/workflow metadata, actor or
  artist consent, likeness review, license, intended use, and approval status;
- replace or exclude any asset that cannot pass the public-release gate;
- self-host approved fonts and define/test CSP.

## 3. Three Authored Bilingual Episodes

- add reviewed English and Brazilian Portuguese fields to canonical packs;
- expand to three distinct educational/comedic arcs with offline playback;
- validate bilingual aliases, media, explanations, sources, and rights receipts;
- keep archive translation and generated drafts outside canonical truth.

## 4. Consented Private Alpha

- export bounded playtest events locally before selecting an analytics sink;
- measure completion, Study use, disputes, learning, replay, and desire for
  another episode;
- collect qualitative feedback on fun, clarity, trust, and host appeal;
- repair repeated failures before adding scope.

## 5. Daily Return Loop

- turn the existing learning ledger into an explainable due-date schedule;
- combine a daily authored show with a short Memory Rematch;
- add local history, earned artifacts, and export before cloud identity.

## 6. Grounded AI Coach

- implement a server-side, provider-neutral gateway with reviewed clue packets
  and approved sources as factual context;
- make output cancellable, source-linked, schema-validated, and visibly
  uncertain when appropriate;
- preserve deterministic Study and host performance during outage or quota loss.

## 7. Commerce After Retention

- consider authored season packs, host packs, and educator/family bundles only
  after players complete, return, and ask for more;
- isolate catalog, entitlement, checkout, refund, deletion, and export from
  gameplay and learning truth.

## Migration Rule

Every Jeopardish subsystem intended for the long-term product receives one
explicit disposition: `PORT`, `REBUILD`, `REFERENCE`, or `RETIRE`. Migrate by
vertical slice with parity tests; do not let the two repositories implement the
same speculative system independently.
