# JeoPARODY Convergence Donor Ledger

This ledger prevents vague instructions to “mine the old repo.” Every candidate
must have provenance, a disposition, a target boundary, and acceptance evidence.

## Dispositions

- **Port:** behavior is strong and can enter the current architecture with modest adaptation.
- **Reinterpret:** preserve the requirement or algorithm, not the implementation.
- **Archive:** useful research or history; no runtime work planned.
- **Reject:** conflicts with current contracts or revives superseded behavior.

## Intake Rule

No donor code is copied until a small ticket records:

1. source repository, commit, and path;
2. behavior worth preserving;
3. current owner receiving that behavior;
4. truth and side-effect boundaries;
5. tests proving parity or improvement;
6. asset/license implications;
7. deletion or archive action for the superseded implementation.

That turns history into a toolbox without turning the runtime into a storage unit.
