# Huddles

Use this folder for brainstorming, creative jams, architecture huddles, and timeboxed group sessions.

Huddle format:

```md
# YYYY-MM-DD - Huddle Topic

Room Type:
Participants:
Timebox:
Human Context:

## Goal

What this huddle is trying to produce.

## Ideas / Notes

- Note

## Keep

- Idea to preserve

## Kill

- Idea to discard

## Park

- Idea to revisit later

## Next Steps

- Action
```
