# Decisions

Use this folder for architecture and product decisions that should outlive a chat session.

Decision format:

```md
# YYYY-MM-DD - Decision Title

Status: proposed / accepted / rejected / superseded
Owner:
Context:

## Decision

What we decided.

## Why

Reasons and tradeoffs.

## Consequences

What this enables, blocks, or risks.

## Follow-ups

- Action
```
